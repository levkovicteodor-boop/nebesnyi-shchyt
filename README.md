# Небесний щит — онлайн-прототип v2

У проєкті є:
- стилізована карта України з областеподібними секторами;
- міста та індикатори їхнього стану;
- три типи ігрових юнітів: дрон, літак, щит;
- переміщення гравців, синхронізація позицій через Socket.IO;
- захоплення секторів, очки, командний чат;
- адаптивний інтерфейс для телефона та комп'ютера.

## Як запустити локально

Потрібен Node.js LTS: https://nodejs.org/

У терміналі, в папці проєкту:
```bash
npm install
npm start
```
Потім відкрий http://localhost:3000.

## Як запросити друзів

`localhost` працює лише на твоєму пристрої. Щоб грати через інтернет, завантаж папку проєкту на Node.js-хостинг, який підтримує WebSocket (наприклад, Render, Railway або власний VPS), задай команду запуску `npm start`, а потім надішли друзям публічну адресу сервісу.

## Обмеження прототипу

Це демонстраційна гра, а не готовий комерційний реліз. Карта стилізована й не призначена для навігації або відображення реальних військових даних. Для публічного запуску варто додати авторизацію, обмеження частоти запитів, стійке збереження прогресу, перевірку дій на сервері та тестування на навантаження.
